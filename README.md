# Sudoku Validator

## 1. Төслийн ерөнхий мэдээлэл

Sudoku Validator нь C програмчлалын хэл дээр хэрэгжүүлсэн, 9×9 хэмжээтэй Судоку хүснэгтийн зөв эсэхийг шалгах програм юм. Програм нь олон урсгалт програмчлалын `pthreads` механизмыг ашиглан хүснэгтийн мөр, багана болон 3×3 хэмжээтэй дэд хүснэгтүүдийг шалгана. Мөн хэрэглэгч програмтай график интерфэйсээр харилцах боломжтой.

**GitHub репозитор:** https://github.com/Naidan2006/sudoku-validator

## 2. Төслийн зорилго

Төслийн үндсэн зорилго нь Судоку хүснэгтийн зөв эсэхийг олон урсгал ашиглан шалгах алгоритм боловсруулах, олон урсгалт програмчлалын зарчмыг хэрэгжүүлэх, график хэрэглэгчийн интерфэйс бүтээхэд оршино.

Төслийн хүрээнд дараах зорилтуудыг хэрэгжүүлнэ.

- Судоку хүснэгтийн мөр, багана болон 3×3 дэд хүснэгтүүдийг шалгах.
- C хэл дээр олон урсгалт програмчлалын механизмыг хэрэгжүүлэх.
- GTK+ 3 ашиглан график интерфэйс боловсруулах.
- Зөв болон буруу өгөгдөл дээр програмын ажиллагааг турших.
- Windows болон Linux орчинд ажиллуулах хувилбар түгээх.

## 3. Ашигласан технологи

| Технологи | Зориулалт |
|---|---|
| C | Програмын үндсэн логик болон алгоритм |
| POSIX Threads (`pthreads`) | Олон урсгал үүсгэх, удирдах |
| GTK+ 3 | График хэрэглэгчийн интерфэйс |
| GCC | C эх кодыг хөрвүүлэх |
| Git, GitHub | Эх кодын хувилбарын удирдлага |
| GitHub Actions | Автомат бүтээх процессыг шалгах |

## 4. Програмын үндсэн ажиллагаа

Судоку хүснэгт нь 9 мөр, 9 багана, есөн ширхэг 3×3 дэд хүснэгтээс бүрдэнэ. Зөв хүснэгтэд мөр, багана болон дэд хүснэгт тус бүрд 1–9 хүртэлх тоо давхцахгүй байх шаардлагатай.

Програм дараах дарааллаар ажиллана.

1. Хэрэглэгч график интерфэйсээр Судоку хүснэгтийн утгуудыг оруулна.
2. Програм хүснэгтийн өгөгдлийг шалгалтын алгоритмд дамжуулна.
3. Мөр, багана болон дэд хүснэгтийн шалгалтуудыг гүйцэтгэнэ.
4. Шалгалтын үр дүнг нэгтгэнэ.
5. Хүснэгтийн зөв эсэхийг хэрэглэгчид харуулна.

## 5. Олон урсгалт програмын бүтэц

Програмд нийт 11 thread ашиглана.

| Thread-ийн төрөл | Тоо | Гүйцэтгэх үүрэг |
|---|---:|---|
| Мөр шалгах thread | 1 | Судоку хүснэгтийн мөрүүдийг шалгах |
| Багана шалгах thread | 1 | Судоку хүснэгтийн багануудыг шалгах |
| Дэд хүснэгт шалгах thread | 9 | Есөн ширхэг 3×3 дэд хүснэгтийг тус тус шалгах |
| Нийт | 11 | Шалгалтуудыг зэрэг гүйцэтгэх |

Thread бүр өөрийн хариуцсан хэсгийг шалгаж, үр дүнгээ үндсэн урсгалд дамжуулна. Үндсэн урсгал нь шалгалтууд дууссаны дараа үр дүнг нэгтгэж, хүснэгтийн нийт төлөвийг тодорхойлно.

Энэ зохион байгуулалт нь мөр, багана болон дэд хүснэгтийн шалгалтуудыг зэрэг гүйцэтгэх боломж олгоно. Бодит гүйцэтгэлийн хурд нь процессорын нөөц, системийн ачаалал болон хэрэгжүүлэлтээс хамаарна.

## 6. Програмыг татаж авах

Програмын бэлэн хувилбаруудыг GitHub Releases хэсгээс татаж авна.

**Хувилбаруудын холбоос:** https://github.com/Naidan2006/sudoku-validator/releases

### 6.1. Windows хувилбар

1. [GitHub Releases](https://github.com/Naidan2006/sudoku-validator/releases) хуудас руу орно.
2. Хамгийн сүүлийн хувилбарыг сонгоно.
3. `Assets` хэсгээс Windows-д зориулсан ZIP багцыг татна.
4. Архивыг задална.
5. `sudoku_gui.exe` файлыг ажиллуулна.

Windows хувилбарын багцад шаардлагатай файлууд байгаа эсэхийг шалгаж, ажиллуулахтай холбоотой нэмэлт зааврыг дагана.

### 6.2. Linux хувилбар

Ubuntu Linux x86_64 орчинд зориулсан хувилбарыг GitHub Releases хэсгээс татаж авна.

[Linux хувилбар татах](https://github.com/Naidan2006/sudoku-validator/releases/latest)

1. `Assets` хэсгээс `Sudoku-Validator-Linux-Ubuntu-x86_64.tar.gz` архивыг татна.
2. Татсан архивын байрлаж буй хавтсанд Terminal нээнэ.
3. Архивыг задална.

```bash
tar -xzf Sudoku-Validator-Linux-Ubuntu-x86_64.tar.gz
```

4. Задалсан хавтас руу орно.
5. `sudoku_gui` файлыг ажиллуулна.

```bash
chmod +x sudoku_gui
./sudoku_gui
```

Нэмэлт зааврыг архив доторх `README-LINUX.txt` файлаас үзнэ. Ажиллуулах файлын нэр архивын бодит агуулгатай таарч байгаа эсэхийг шалгана.

## 7. Эх кодоос хөрвүүлэх

Linux орчинд эх кодыг хөрвүүлэхэд GCC, GTK+ 3 хөгжүүлэлтийн сан болон `pkg-config` шаардлагатай.

Шаардлагатай сангуудыг суулгах команд:

```bash
sudo apt update
sudo apt install build-essential git libgtk-3-dev pkg-config
```

Репозиторыг татах:

```bash
git clone https://github.com/Naidan2006/sudoku-validator.git
cd sudoku-validator
```

График интерфэйстэй хувилбарыг хөрвүүлэх команд:

```bash
gcc gui.c sudoku_core.c -o sudoku_gui \
    $(pkg-config --cflags --libs gtk+-3.0) -pthread
```

Програмыг ажиллуулах:

```bash
./sudoku_gui
```

Эдгээр команд нь эх кодын файлууд репозиторын үндсэн хавтаст байрлаж байгаа нөхцөлд зориулагдсан. Консолын хувилбарыг хөрвүүлэх команд болон шаардлагатай тохиргоог эх кодын бодит бүтэцтэй тулгана.

## 8. Тест ба баталгаажуулалт

Програмын ажиллагааг зөв болон буруу оролтын өгөгдлөөр шалгана.

| Тестийн төрөл | Шалгах нөхцөл |
|---|---|
| Зөв Судоку хүснэгт | Бүх мөр, багана, дэд хүснэгт хүчинтэй эсэх |
| Мөрийн давхардал | Нэг мөрөнд ижил тоо давтагдсан эсэх |
| Баганын давхардал | Нэг баганад ижил тоо давтагдсан эсэх |
| Дэд хүснэгтийн давхардал | 3×3 хэсэгт ижил тоо давтагдсан эсэх |
| Хоосон нүд | Хоосон оролтыг програм хэрхэн боловсруулах |
| Буруу оролт | Зөвшөөрөгдөөгүй утгыг зөв боловсруулах эсэх |

Тест бүрийн хүлээгдэж буй үр дүнг програмын бодит үр дүнтэй харьцуулж, илэрсэн алдаа болон засварыг баримтжуулна.
