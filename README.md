# Төслийн баримтжуулалт

Энэ хавтас нь олон урсгалт Sudoku шалгах програмын хэрэглэгчийн заавар болон ажиллагааны нотлох зургуудыг агуулна.

## Файлууд

- `Manual.pdf` — програмыг ажиллуулах, ашиглах болон түгээмэл алдааг шийдвэрлэх заавар.
- `screenshots/` — зөв болон буруу Sudoku шалгасан үр дүнгийн screenshot зургууд.

## Туршилтын үр дүн

1. Зөв Sudoku оруулахад `Sudoku result: VALID` гэж гарна.
2. Буруу Sudoku оруулахад `Sudoku result: INVALID` гэж гарна.
