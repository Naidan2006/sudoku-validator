# Олон урсгалт Sudoku шалгах програм

## 1. Төслийн танилцуулга

Энэхүү төсөл нь C програмчлалын хэл болон POSIX Threads (`pthread`) технологийг ашиглан 9×9 хэмжээтэй Sudoku хүснэгтийн зөв эсэхийг шалгах програм юм. Програм нь график хэрэглэгчийн интерфэйстэй бөгөөд хүснэгтийн мөр, багана болон 3×3 хэмжээтэй дэд хүснэгтүүдийн утгуудыг шалгаж, үр дүнг хэрэглэгчид харуулна.

Програм нь Sudoku-г бодож бөглөхгүй. Харин хэрэглэгчийн оруулсан өгөгдөл Sudoku-ийн үндсэн дүрмүүдийг хангаж байгаа эсэхийг шалгана.

## 2. Төслийн зорилго

Төслийн зорилго нь үйлдлийн системийн олон урсгалт боловсруулалтын зарчмыг практикт хэрэгжүүлэх, POSIX Threads ашиглан өгөгдлийг зэрэг шалгах болон график интерфэйсээр үр дүнг хэрэглэгчид ойлгомжтой харуулахад оршино.

## 3. Үндсэн боломжууд

- 9×9 хэмжээтэй Sudoku хүснэгтэд өгөгдөл оруулах.
- Мөр тус бүрийн утгуудыг шалгах.
- Багана тус бүрийн утгуудыг шалгах.
- 3×3 хэмжээтэй дэд хүснэгтүүдийг шалгах.
- Олон урсгал ашиглан шалгалтын ажиллагааг гүйцэтгэх.
- Шалгалтын үр дүнг `PASS`, `FAIL`, `VALID`, `INVALID` төлөвөөр харуулах.
- Хоосон нүд болон зөвшөөрөгдөөгүй утгыг илрүүлэх.
- Оруулсан өгөгдлийг цэвэрлэж, дахин шалгах.
- Програмын ашиглалтын зааврыг график интерфэйсээс харах.

## 4. Ашигласан технологи

| Технологи | Зориулалт |
|---|---|
| C | Програмын үндсэн логикийг хэрэгжүүлэх |
| POSIX Threads (`pthread`) | Олон урсгалт боловсруулалт |
| GTK3 | График хэрэглэгчийн интерфэйс |
| GCC | C эх кодыг хөрвүүлэх |
| GitHub | Эх код болон баримт бичгийг хадгалах |
| GitHub Actions | Автомат хөрвүүлэлт, шалгалтын ажлын урсгал |

## 5. Програмыг татаж авах, ажиллуулах

### 5.1. Windows хувилбар

Програмын бэлэн хувилбарыг дараах холбоосоор татаж авна.

[Sudoku Validator for Windows v1.0.1](https://github.com/Naidan2006/sudoku-validator/releases/tag/v1.0.1)

Ажиллуулах дараалал:

1. Release хуудаснаас `Sudoku-Validator-Windows.zip` файлыг татаж авна.
2. Татаж авсан ZIP файлыг задална.
3. Задалсан хавтас доторх `sudoku_gui.exe` файлыг ажиллуулна.
4. Програмын эхлэх цонхонд байрлах тоглоом эхлүүлэх товчийг дарна.
5. Sudoku хүснэгтийн нүднүүдэд 1–9 хүртэлх цифр оруулна.
6. Бүх нүдийг бөглөсний дараа шалгах товчийг дарж үр дүнг харна.

Бэлэн хувилбарыг ажиллуулахын тулд хэрэглэгч эх кодыг өөрөө хөрвүүлэх шаардлагагүй. Гэхдээ бусад компьютер дээр ажиллах боломж нь үйлдлийн систем болон шаардлагатай runtime сангуудын нийцтэй байдлаас хамаарна.

### 5.2. Эх кодыг хөрвүүлэх

Эх кодыг өөрчлөх болон хөгжүүлэх тохиолдолд Windows орчинд MSYS2 UCRT64, GCC, GTK3 болон `pkg-config` шаардлагатай.

MSYS2 UCRT64 терминалд төслийн хавтас руу орно. Доорх зам нь төслийн хавтас `C:\OS-BD1\sudoku-validator` байршилд байгаа жишээ юм.

```bash
cd /c/OS-BD1/sudoku-validator
```

График интерфэйстэй хувилбарыг хөрвүүлэх команд:

```bash
gcc gui.c sudoku_core.c -o sudoku_gui.exe -pthread $(pkg-config --cflags --libs gtk+-3.0)
```

Хөрвүүлэлт амжилттай дууссаны дараа програмыг ажиллуулна.

```bash
./sudoku_gui.exe
```

Терминалын хувилбарыг хөрвүүлэх команд:

```bash
gcc -Wall -Wextra -pthread main.c -o sudoku_validator.exe
```

Програмыг ажиллуулах команд:

```bash
./sudoku_validator.exe
```

Эдгээр командыг ашиглахын өмнө эх кодын файлууд төслийн хавтаст байгаа эсэх болон шаардлагатай сангууд зөв суусан эсэхийг шалгана.

## 6. Програм ашиглах заавар

1. График интерфэйстэй програмыг ажиллуулна.
2. Тоглоом эхлүүлэх товчийг дарна.
3. 9×9 хүснэгтийн нүд бүрд 1–9 хүртэлх цифр оруулна.
4. Мөр, багана болон 3×3 дэд хүснэгт тус бүрд ижил цифр давхардуулахгүй.
5. Шалгах товчийг дарж шалгалтын үр дүнг харна.
6. Дахин шалгах шаардлагатай бол цэвэрлэх товчийг ашиглан хүснэгтийг хоосолж, шинэ өгөгдөл оруулна.

## 7. Шалгалтын үр дүнгийн тайлбар

| Төлөв | Тайлбар |
|---|---|
| `PASS` | Тухайн шалгалт амжилттай болсон |
| `FAIL` | Тухайн шалгалтаар алдаа илэрсэн |
| `VALID` | Шалгалтын нөхцөлүүд амжилттай хангагдсан |
| `INVALID` | Нэг буюу хэд хэдэн шалгалтаар алдаа илэрсэн |

Үр дүнг тайлбарлахдаа мөр, багана болон дэд хүснэгтүүдийн шалгалтын төлөвийг хамтад нь авч үзнэ.

## 8. Туршилтын тохиолдлууд

Програмын ажиллагааг дараах нөхцөлүүдээр шалгана.

| № | Туршилтын нөхцөл | Хүлээгдэж буй үр дүн |
|---|---|---|
| 1 | Зөв бөглөсөн Sudoku оруулах | Шалгалтууд амжилттай болж, `VALID` үр дүн гарах |
| 2 | Нэг нүдийг хоосон үлдээх | Хоосон нүдний талаар мэдэгдэл гарах |
| 3 | 0 утга оруулах | Зөвшөөрөгдөөгүй утгын талаар мэдэгдэл гарах |
| 4 | Мөр, багана эсвэл дэд хүснэгтэд цифр давхардуулах | Холбогдох шалгалт `FAIL` болж, `INVALID` үр дүн гарах |
| 5 | Цэвэрлэх товчийг дарах | Хүснэгт болон өмнөх үр дүн цэвэрлэгдэх |

Хүснэгтэд дурдсан үр дүнг тухайн хувилбарыг ажиллуулж туршсаны дараа баталгаажуулна.

## 10. Дүгнэлт

Энэхүү төсөл нь Sudoku хүснэгтийн зөв эсэхийг шалгах ажиллагааг олон урсгалт боловсруулалтын аргаар хэрэгжүүлж, үр дүнг график интерфэйсээр харуулах боломжийг бүрдүүлсэн. Төсөл нь C хэл, POSIX Threads болон GTK3 технологийн хэрэглээг практикт хэрэгжүүлэх зорилготой.

## 11. Хиймэл оюуны хэрэглээ

Төслийн баримт бичиг боловсруулах, кодын ажиллагааг тайлбарлах болон туршилтын тохиолдлуудыг төлөвлөхөд ChatGPT-ийн тусламж ашигласан. Програмын ажиллагаа болон туршилтын үр дүнг бодитоор ажиллуулж баталгаажуулах шаардлагатай.
